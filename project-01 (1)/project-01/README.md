# CineVault — Project 01

A component-based React SPA for browsing, searching, and filtering a curated movie dataset.

## Features
- **Main Page**: Search bar + sort control + genre filter pills — all state combined simultaneously using `.filter()` and `.sort()`.
- **Login & Register Pages**: Placeholder forms (non-functional, UI only).
- **About Page**: Team info, tech stack, project description.
- **Persistent Header** with client-side routing (React Router v6).
- **Fully Responsive** — desktop and mobile layouts.

## Tech Stack
- React 18 (functional components + hooks)
- React Router v6
- CSS3 (custom properties, flexbox, grid, media queries)
- Deployed on **Render.com** (Static Site)

## Getting Started

```bash
npm install
npm start
```

## Build for Production

```bash
npm run build
```

## Render.com Deployment
- **Build Command**: `npm run build`
- **Publish Directory**: `build`
